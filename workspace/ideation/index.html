The chevrons become optics

Your triple-chevron mark is extruded as glass and laid flat on a bench. The beam is traced through its real outline. Each wavelength refracts on its own, and steep hits bounce inside the glass by total internal reflection. Then bloom turns the paths into laser light.

  • Diamond glass traps light in the chevron arms. Try it.
  • Dispersion is turned up about 3× so the fan shows across the bench. Through parallel faces the colors would otherwise recombine.
  • On the real site, scroll moves the emitter along the bench.
teaches → refraction through any polygon, critical angle θc = asin(1/n)

The brand is the physics

A white beam hits a prism and splits into the thin rainbow. The aesthetic you like stops being decoration and becomes the result of a real simulation, Snell's law at seven wavelengths.

  • Hero is this bench. Name set in thin Unbounded, the beam passes through it.
  • Each project section is a new optical element: mirror, lens, slit.
  • Scrolling rotates the prism, so the rainbow sweeps down the page with you.

Recommendation

Lead with A, let Pip live in it, build every demo as a block

The optics bench is the strongest pitch because the rainbow is earned by physics, which is exactly Brilliant's job. Pip (C) adds the warmth a pure-physics site lacks. B and D become blocks inside the site, not competing homepages. Under the hood, every demo is defined by a small typed spec that a person or an AI can read and remix, which answers the listing's API line directly.

// blocks/prism.ts · every interactive is data first
export const prism = block({
  id: "prism-dispersion",
  teaches: "n₁ sin θ₁ = n₂ sin θ₂",
  params: {
    glass:    oneOf(["crown", "flint", "diamond"]),
    rotation: angle({ min: -30, max: 30 }),
    aim:      point(),
  },
  observe: ["incidence", "deviation"],
  describe: (s) =>
    `Beam enters at ${s.incidence}°, spreads ${s.spread}°`,
});

Why a spec, and not just code

Brilliant wants blocks experts and AIs can both compose. If every demo is a typed object with params, observable values and a plain-language describe, then the same spec drives the canvas, the screen-reader text, the keyboard controls and an agent's tool call. One source, four outputs. Your site becomes a small version of their platform.
