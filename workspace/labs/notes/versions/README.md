# Old versions

Snapshots of each lab from before a decisive change, kept for talking about process. File names start with the version number, then say what that version was, e.g. `13-burst-finale.html`. The behind-the-scenes log (`../behind-the-scenes.md`) says why each one changed.

They import the live `labs/shared/` files (rewritten to `../../../shared/`), not the shared code as it stood at the time. So an old version may render slightly differently, or not run at all, where the shared code has moved on. Serve the repo root and open e.g. `/labs/notes/versions/sand/01.html`.
